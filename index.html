ทดสอบโหลด Happitat

จำลองหลายเครื่องบันทึกพร้อมกัน เพื่อดูว่าระบบรับไหวก่อนเปิดหลายบูธ

ก่อนเริ่ม

  1. admin สร้างบูธรหัส LOADTEST ที่เมนู จัดการบูธ (เปิดใช้งาน · Staff IDs เว้นว่าง)
  2. ทดสอบช่วงที่ไม่มีพนักงานใช้งานจริง เพราะทุกคนใช้คิวและโควตาของ Google ร่วมกัน
  3. เสร็จแล้วลบข้อมูลทดสอบ: Apps Script → เลือก cleanupLoadTest → Run แล้วปิดบูธ LOADTEST

ข้อมูลทดสอบบันทึกลงชีตจริงทั้งหมด (เฉพาะบูธ LOADTEST) ไม่กระทบยอดของบูธอื่น
